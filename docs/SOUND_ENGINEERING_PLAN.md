# 声学工程计划：现有设备逼近 Galloway（2026-08-29）

设备冻结：iPhone 16e + DJI Mic Mini 2 + 三脚架 + 家里现有软物。不买硬件。
目标：录制端榨干设备 + 软件端建一条处理链，让成片声音尽量贴近 Scott 的基准 reel。

## 记分板（每轮实验都量这五项）

| 指标 | 现状（DJI 基线）| Scott | 目标 |
|---|---|---|---|
| RT60（房间感）| 0.23 s | 0.14 s（棚）| ≤ 0.18 s |
| 语音/底噪动态 | 65–67 dB | 71 dB | ≥ 69 dB |
| 咔声密度（4kHz 高通脉冲计数）| 3.3 个/秒 | — | ≤ 0.5 个/秒（成片）|
| LTAS 频谱差（1.6–12 kHz，相对 Scott）| 薄 9–16 dB | 0 | 每段 ≤ 3 dB |
| 响度起伏 LRA | 6.4 LU | 4.5 LU | ≈ 4.5 LU |

测量脚本按 memory `video-audio-clicks-and-baseline.md` 里的方法重建；Galloway 参考 `yt-dlp instagram.com/reel/C5Y7GROAkEW`。

## Phase 1 — 录制实验阶梯（Hao，一次约 25 分钟）

不搞全排列：11 段 × 30 秒，一次只动一个变量，能单独归因。
（Hao 确认：降噪/增益/毛球从未动过 → 基线即"降噪关 · 默认增益 · 无毛球"，无需单独的"降噪关"对照条。）

**控制条件（全程不变）**：同一房间同一站位（站着录正片的位置，不用晚上那个有低频嗡嗡声的座位）、手机和三脚架位置不动、念同一段 30 秒文字、正常音量。**每段开头念"测试 N"**，用它自动对号。

| # | 变量 | 设置 |
|---|---|---|
| T1 | 基线 | 现习惯原样：麦胸口、降噪关、默认增益、无毛球 |
| T2 | 麦位 | 领口最高点（离下巴 <15 cm），身体一动不动 |
| T3 | 麦位+动作 | 同 T2 位置，正常做手势 |
| T4 | 麦位 | 塞衣服里，一动不动 |
| T5 | 麦位+动作 | 塞衣服里，正常做手势 |
| T6 | 降噪 | 用 T1–T5 里赢的麦位：降噪 basic |
| T7 | 降噪 | 同上：降噪 strong |
| T8 | 增益 | 降噪回 basic，抬增益（说话打到黄区，原始峰值 -12 ~ -8 dBFS）|
| T9 | 毛球 | 戴附带防风毛球 |
| T10 | 房间 | 晾衣架挂毛毯立在手机后（挡住 Hao 面对的墙，不入镜）|
| T11 | 决赛圈 | 全部赢家设置合体录一条 |

T2–T5 同时就是咔声悬案实验：只在 T4/T5 出现 → 衣服碰麦壳；四条都有 → 口腔音。

## Phase 2 — 分析定标（Claude）

11 段全量跑记分板 → 每个变量给结论 → 产出一页《标准录制协议》（麦位/降噪/增益/毛球/布置的最终设置）写进 `VIDEO_FORMAT_REFERENCE.md`。以后每集照做，不再凭感觉。

## Phase 3 — 软件处理链（Claude，用现有素材即可开工）

按顺序建链、逐级验收（每级：指标 + 给 Hao 的 A/B + diff 轨）：

1. **去咔声**：自研脉冲检测 + AR 插值修复（ffmpeg adeclick 已证不够，见 `AUDIO_DECLICK_BRIEF.md`）。验收：咔声计数降 80%+，diff 轨无语音。
2. **高通 80 Hz**：清掉低频嗡嗡与手持震动。
3. **轻降噪**（afftdn 保守参数）：只削稳态底噪，换 3–5 dB 动态。
4. **EQ 匹配 Galloway**：已测得差值曲线（200–400 Hz +3 dB 胸声、1.6–6.3 kHz +6~9 dB 清晰度、6.3 kHz+ 高架 +10 dB 空气感，随 Phase 1 麦位结果重测）。这是音色差距最大的一张牌。
5. **De-esser**：EQ 抬了 5–8 kHz 之后齿音必须压回去。
6. **压缩**（acompressor ≈2:1）：LRA 6.4 → 4.5，出 Scott 那种句句顶在你面前的密度。
7. **loudnorm -14 LUFS**（已有，保持在链条最后）。
8. 视 Phase 1 结果：RT60 仍 >0.20 s 才考虑加温和版尾音扩展器（上次激进版 Hao 已否）。

可选支线（唯一花钱项，US$30 左右）：若定性为口腔音且第 1 步修不干净，买 iZotope RX Elements 用 Mouth De-click。

## Phase 4 — 验收与落地

1. 决赛圈素材走完整处理链 → 和 Scott 的 30 秒并排盲听（A/B 随机顺序），Hao 打分。
2. 通过后：处理链进 `scripts/video-pipeline/encode.py`（去咔在 loudnorm 前），录制协议进 `VIDEO_FORMAT_REFERENCE.md`，记分板终值存 memory。
3. 用新协议+新链重录/重制下一集，上线对比数据留档。
