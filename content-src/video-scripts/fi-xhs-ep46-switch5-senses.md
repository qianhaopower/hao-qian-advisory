## 正文
压力保护开关 5/5:五感。听觉、嗅觉、触觉、视觉。
　
大脑有两种运行模式:一种叫 default network,一种叫 active network。我们很焦虑的时候,其实是 default network 占主导——在想未来的事、想过去的事,唯独没有想现在的事。这时人就容易陷入压力和焦虑。相反,当 active network 占主导时,我们会聚焦在此时此刻,不是今天,而是真正的这一秒。
　
不知道你有没有过那种瞬间:看着窗外的树叶在摇动,和风煦日,时间静静流逝,好像一切都被按下了暂停键。那就是 active network 在某一瞬间占了主导。所以我们可以有意识地启动它,让焦虑下降。
　
具体怎么做?很简单,开启你的五感。压力很大的时候:先听一个声音——窗外好像有鸟叫,听觉就启动了;再看一个东西——外面树叶在摇,边缘是红色的,洒着阳光,视觉启动了;再闻一个气味——我现在闻到一点咖啡味,早上的杯子还没收;再摸一个东西——摸一下旁边的墙,凉凉的,有起起伏伏的纹理,触觉也启动了。视觉、听觉、嗅觉、触觉整个被启动,active network 就更活跃,压一压 default network,也就压一压焦虑。学名叫 sensory grounding。
　
连着拍了五条,讲了五个压力保护开关:视觉、眼部肌肉、表情、呼吸、五感。我把它们打在了片尾。希望在艰难困苦的时候,你会想起其中一两条,花一两分钟做一下,让自己稍微好受一些。共勉。
